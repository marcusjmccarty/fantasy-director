Automatic playback

Install the Fantasy Stream Playback helper once in desktop Chrome. It starts supported embedded videos, prepares the next game silently, keeps fullscreen on your channel, and turns subtitles off.

Download playback helper · 1.1.0

  1. Extract the ZIP and keep the folder somewhere permanent.
  2. Open chrome://extensions in Chrome and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Reload Fantasy Stream. Click Start watching and enter Full screen once.

If updating an existing Playback helper, replace its folder contents and click Reload on its extension card. The older Fantasy Director extension is a different program.

The helper requests website access because embedded players use different domains. It activates only inside Fantasy Stream tabs, does not read cookies or your fantasy account, and does not send browsing data anywhere. Safari and mobile browsers do not support this Chrome extension. A provider may still require its own sign-in or consent; subtitles baked into the video cannot be removed.
